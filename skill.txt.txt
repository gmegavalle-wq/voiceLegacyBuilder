SKILL: Clonador de Voz Local - Mobile App (Gratuito)
PROPÓSITO DE ESTA SKILL
Guiar la creación de código para una app móvil que permite clonar la voz de cualquier persona:

Fase de entrenamiento: El usuario graba 5-10 ejemplos cortos de su voz (10-30 segundos cada uno)
Procesamiento local: TensorFlow Lite extrae características biométricas de la voz (embeddings)
Síntesis: El usuario escribe texto → la app sintetiza ese texto CON SU VOZ CLONADA
Privacidad total: Todo ocurre en el dispositivo, sin internet, sin servidores, sin APIs de pago


STACK TÉCNICO OBLIGATORIO (GRATUITO)

Framework: React Native + Expo
Grabación de audio: expo-av (Audio Recording)
Almacenamiento local: expo-file-system + async-storage
Procesamiento IA: TensorFlow Lite (gratuito, open-source)
Síntesis de voz: Glow-TTS + HiFi-GAN (modelos ONNX/TFLite gratuitos)
Sin APIs de pago: PROHIBIDO ElevenLabs, Google Cloud TTS, AWS Polly, Azure, etc.
Modelos usados:

Whisper (para transcripción opcional, gratuito)
Glow-TTS (síntesis de voz, gratuito)
HiFi-GAN (vocoder para audio de calidad, gratuito)
SpeechBrain embeddings (extracción de características de voz, gratuito)

Patrón de almacenamiento seguro
javascript// Todo en el dispositivo, nada en la nube
const guardarVozEntrenada = async (audioFiles, embeddings) => {
  try {
    const ruta = FileSystem.documentDirectory + 'voice_training/';
    
    // Crear carpeta si no existe
    await FileSystem.makeDirectoryAsync(ruta, { intermediates: true });
    
    // Guardar audios originales (para referencia)
    audioFiles.forEach(async (file, index) => {
      await FileSystem.copyAsync({
        from: file,
        to: `${ruta}training_${index}.m4a`
      });
    });
    
    // Guardar embeddings (características biométricas)
    const metadata = {
      id: Date.now(),
      fechaEntrenamiento: new Date().toISOString(),
      cantidadAudios: audioFiles.length,
      // embeddings es Array[192] de números flotantes
      embeddings: embeddings,
    };
    
    await AsyncStorage.setItem(
      'VOICE_PROFILE',
      JSON.stringify(metadata)
    );
    
    return true;
  } catch (error) {
    console.error('Error guardando voz:', error);
    return false;
  }
};

import React, { useState } from 'react';

export default function PrimaryButton({
  onPress,
  label,
  accessibilityLabel,
  variant = 'primary'

  return (
    <TouchableOpacity

  );
}

MODELOS DE IA GRATUITOS (REFERENCIAS)
Speech Embedding (extracción de características)

SpeechBrain (MIT License): Extrae embeddings de voz
Descripción: Convierte audios en vectores [192] que representan las características únicas de una voz
Peso: ~20-40 MB compilado para TFLite
Precisión: 95%+ en speaker verification

Síntesis de voz (TTS)

Glow-TTS (Apache 2.0): Síntesis rápida de texto a espectrograma
Peso: ~30-50 MB
Velocidad: 5x más rápido que tiempo real

Vocoder (audios naturales)

HiFi-GAN (MIT License): Vocoder neural, audio alta calidad
Peso: ~10-15 MB
Salida: Audio natural y inteligible

Transcripción (opcional)

OpenAI Whisper Tiny (MIT License): Transcripción de audio
Peso: ~30 MB
Precisión: 90%+ en español
